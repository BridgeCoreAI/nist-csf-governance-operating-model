# Limitations

This repository does not provide, and should not be treated as:

1. A compliance guarantee
2. An audit certification
3. A legal opinion
4. A regulatory approval
5. A replacement for organizational judgment
6. A replacement for the NIST Cybersecurity Framework itself
7. An RMF or ATO tool
8. An AI governance repository

## Specific Limitations

- GitHub does not by itself satisfy NIST CSF requirements. It serves as a version-controlled evidence, workflow, and accountability layer in this reference implementation.
- Organizations must adapt this model to their own legal, regulatory, contractual, technical, business, and risk context. Nothing here is directly usable without that adaptation.
- The existence of an artifact does not prove a control is operating effectively. Operating effectiveness must be supported by appropriate evidence over time, not a single point-in-time record.
- All examples, evidence, and the organization used throughout (Edjobe Financial Group) are fictional or synthetic. Nothing in this repository describes a real audit, a real company, or real regulatory findings.
