# Security

This repository must never contain:

1. Client information
2. Employer information
3. Real audit evidence
4. Confidential policies
5. Internal contracts
6. Real vulnerabilities
7. Credentials
8. Tokens
9. API keys
10. Personal information
11. Restricted architecture
12. Production logs
13. Sensitive meeting minutes
14. Unreleased BridgeCore AI intellectual property
15. Private repository references

If you believe any of the above has been inadvertently included in this repository, please report it immediately rather than opening a public issue.
