# Governance

This document describes how this public repository itself is governed, distinct from the GOVERN function content the repository demonstrates.

## Decision Authority

Grace M. Adjeli, as founder of BridgeCore AI LLC, holds final decision authority over this repository's content, structure, and release schedule.

## How Content Reaches This Repository

All content in this repository has passed through a private development and publication review process before appearing here. This repository does not accept direct external contributions of governance content (control records, evidence, registers). See CONTRIBUTING.md for what kinds of contributions are welcome.

## Review Requirements

Every control record, template, and register in this repository has been reviewed for evidence support, gap-specific recommendations, and consistency with the stated maturity and assessment models before release.

## Versioning

This repository uses semantic versioning. See CHANGELOG.md for release history and templates/ for the current structure of every artifact type.

## Scope Discipline

This repository is built in controlled batches. The current release covers GV.OC only. Future GOVERN categories are represented in the roadmap only, not as partially built content, until they are the subject of an explicitly scoped future release.
