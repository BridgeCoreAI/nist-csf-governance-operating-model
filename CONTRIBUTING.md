# Contributing

This repository is a reference implementation and portfolio project. It welcomes certain kinds of contribution and does not accept others.

## Welcome

- Corrections to factual errors, broken links, or inconsistent identifiers
- Clarifications to documentation that is genuinely ambiguous
- Suggestions for improving templates, as issues, for maintainer review
- Questions about the approach, as GitHub Issues

## Not Accepted

- Real organizational evidence, client data, or employer data of any kind
- Direct pull requests adding new control records or GOVERN categories, since all governance content here goes through an internal development and publication review process before release
- Changes that alter the fictional/synthetic nature of any example without maintainer review

## How to Contribute a Correction

1. Open an issue describing the specific problem.
2. If the fix is small and unambiguous (a typo, a broken link), a pull request referencing the issue is welcome.
3. Larger suggestions will be reviewed and, if adopted, implemented through the repository's normal development process rather than merged directly.

## Code of Conduct

Be direct, be specific, and keep feedback focused on the content. This repository is maintained as professional portfolio and reference work.
